# Code of conduct

This project exists to teach. Everyone who takes part, in issues, pull requests, discussions or the classroom, is expected to:

- Be patient with beginners. A question that seems obvious is the reason this repository exists.
- Critique the work, not the person. Point at the cell, the slide or the sentence and say what would be clearer.
- Give credit and cite sources. Numbers, quotes and diagrams carry their origin.
- Keep it professional. No harassment, discrimination, personal attacks or unwelcome sexual attention, anywhere the project is discussed.
- Respect privacy. Never post personal data about students or anyone else, and never paste credentials.

Maintainers may edit, hide or remove contributions that break these rules and may block repeat offenders. To report a problem, open an issue if it can be public, or use the private reporting option in the repository's Security tab if it cannot.

This text follows the spirit of the Contributor Covenant in plain language.
